ZEMLYANOVVA EPOXY V6 — обновление сайта с интерактивной 3D-тумбой

Репозиторий: https://github.com/trofimmokrov-netizen/ksusha_epoxy_premium

Загрузите содержимое архива В КОРЕНЬ main (не вкладывайте папку внутрь папки).
1. Откройте репозиторий на GitHub.
2. Add file → Upload files.
3. Перетащите разархивированные файлы и папку assets.
4. Внизу выберите Commit changes.
5. Проверьте в Settings → Pages публикацию из main / (root).

Сайт: index.html
3D просмотр тумбы: tumba-3d.html
Изображение: assets/images/tumba-pink.jpg

Действующая форма Bitrix24 и кнопка Bitrix24 оставлены в index.html.
3D-визуализация является интерактивной реконструкцией по изображению, не точной CAD-моделью.
Внешние ресурсы: Google Fonts, Bitrix24. Для них требуется интернет.
