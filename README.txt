КАК ДОБАВИТЬ НОВУЮ РАБОТУ
1. Скопировать фото в assets/images/
2. Открыть site-data.js
3. Добавить объект:
   { image: "assets/images/имя.jpg", title: "Название", type: "Описание", featured: false }
4. featured: true делает карточку шире.
