# Сохранение и отправка проектов

Общий компонент projects.js/projects.css подключён к конструктору и примерке. Блок «Сохранить проект / поделиться» позволяет назвать текущий проект и:

- сохранить до 30 именованных вариантов в localStorage этого браузера;
- открыть библиотеку «Мои проекты», редактировать, примерить или удалить вариант;
- скачать JSON-файл проекта и открыть его на другом устройстве;
- скопировать самодостаточную ссылку;
- открыть нативное меню отправки, выбор получателя Telegram или черновик сообщения Ксении.

Отправка подтверждается посетителем. Ссылки содержат нормализованную компактную конфигурацию k2 и название проекта; идентификатор записи localStorage другому человеку не нужен. В примерке дополнительно сохраняются поворот, наклон камеры, масштаб и смещение предмета. Эти значения проверяются по диапазонам при восстановлении. Фото комнаты и видео камеры не включаются в localStorage, JSON или ссылку. Готовое изображение с комнатой можно сохранить существующей кнопкой PNG.

Библиотека доступна также с главного экрана Mini App кнопкой «Мои сохранённые проекты». Внутри Telegram используются те же формы; кнопка назад закрывает открытый диалог библиотеки перед выходом в предыдущий раздел. Настройки iframe разрешают clipboard-write и web-share, когда клиент их поддерживает. При отказе буфера обмена ссылка доступна для ручного копирования.

Это локальное сохранение без аккаунта и автоматической синхронизации между браузерами. При очистке данных браузера проекты удалятся; для переноса/резервной копии нужен файл или ссылка. Сбой хранилища и лимит 30 проектов не удаляют существующие записи и показывают альтернативу. Названия выводятся с экранированием. Импорт принимает только JSON проекта версии 1 до 100 КБ с известным изделием и нормализует параметры.

KSUSHA_PROJECT_CONTEXT.get() — локальный интерфейс текущей конфигурации и ракурса; ksusha-project-changed уведомляет компонент об изменениях. Обновление ссылок при анимации ограничено и выполняется только при открытом блоке. Нет запросов к серверу сохранения и токенов в коде.

projects-check.cjs проверяет 390/1280: именованное сохранение, перезагрузку, экранирование названия, открытие редактирования, копирование и нативную отправку (имитируются), Telegram-ссылку, реальное скачивание JSON, импорт, отклонение постороннего файла, восстановление ракурса и доступ к библиотеке внутри iframe Mini App. Сообщения и заявки не отправляются.

Если полная ссылка длиннее 3500 символов, отправка через Telegram предлагает использовать JSON-файл, чтобы сообщение не обрезало конфигурацию. Копирование полной ссылки для браузера остаётся доступным.
