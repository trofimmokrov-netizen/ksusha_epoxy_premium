ZEMLYANOVVA EPOXY — обновление сайта, версия 5 (16.10.2026)

РЕПОЗИТОРИЙ
https://github.com/trofimmokrov-netizen/ksusha_epoxy_premium

ЧТО В АРХИВЕ
index.html — новая версия главной страницы с встроенными стилями и скриптами.

УСТАНОВКА
1. Распакуйте архив на телефоне или компьютере.
2. Откройте репозиторий на GitHub в браузере и перейдите в корень проекта.
3. Через Add file → Upload files загрузите файл index.html с заменой существующего.
   На телефоне при необходимости включите «Версия для ПК» в браузере.
4. Подтвердите Commit changes в ветку main.
5. Подождите публикации GitHub Pages, если он включён, затем обновите страницу.

ВНИМАНИЕ
- Не удаляйте каталоги assets/images/, assets/video/ и assets/posters/.
- Не удаляйте site-data.js: новая страница продолжает читать из него каталог.
- Старые app.js и styles.css могут оставаться в репозитории, но новая страница не подключает их.
- Не загружайте ZIP как файл сайта: распакуйте его и загрузите именно index.html.
- Фото и видео подтягиваются по относительным путям из уже существующей папки assets/.
- Для локального запуска вне репозитория фото и видео тоже должны лежать в assets/ рядом с HTML.
- CRM Bitrix24 использует прежнюю inline-форму и плавающую кнопку; проверить реальную отправку заявки следует после публикации.
- Встроенный конструктор идеи копирует описание в буфер, но НЕ заполняет поля Bitrix автоматически.

ЧТО УЛУЧШЕНО
- Переработана главная страница: тёмный зелёный, натуральная бумага, золотистые акценты.
- Анимация появления секций, медленное движение главного фото, бегущая строка и индикатор прокрутки.
- Модальное увеличение проектов с переключением стрелками, клавиатурой и свайпом.
- Каталог без повторных карточек с ценами для фотографий деталей.
- Восемь видео мастерской в прокручиваемой ленте плюс основное видео.
- Видео загружаются по требованию, пауза при уходе за экран и скрытии вкладки.
- Мобильное меню и фиксированная кнопка заявки внизу экрана.
- Мини-конструктор формы столешницы и оттенка смолы; копирование описания.
- SEO-описание, карточка ссылки, иконка сайта, поддержка reduced motion.
- Сохранены телефон, Instagram, форма заявки и плавающая кнопка Bitrix24.

СТАТУС ПУБЛИКАЦИИ
Из-за ограничений подключённой интеграции GitHub автоматически закоммитить изменения не удалось (GitHub API 403 на создании ветки). Подготовленный файл прошёл локальную проверку структуры, JavaScript и интерактивности. Проверка живой формы CRM и опубликованных медиаресурсов возможна после обновления сайта.
